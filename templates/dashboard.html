System Architecture Overview

Unified monolithic Flask implementation fulfilling laboratory assignment guidelines

System Details

Single Unified Backend

All four laboratory practicals run under a single Flask instance at http://127.0.0.1:5000. Flask Blueprints separate modular logic cleanly while sharing base Jinja2 layouts and CSS styles.

SQLite Relational Engine

Practicals 3 and 4 persist data to instance/management.db. Queries use parameterized SQL to guarantee integrity and protect against SQL injection vulnerabilities.

Academic Compliance

Practical 1 and Practical 2 demonstrate stateless form processing and validation, while Practicals 3 and 4 provide complete database-driven lifecycle operations as specified in the curriculum.
