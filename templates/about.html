About Flask Management Systems

Unified Python Flask web application integrating four laboratory practicals under a single administrative dashboard.

Read Practical Documentation

Project Motivation & Architecture

The Flask Management Systems platform unites four distinct academic practical assignments into a single, cohesive, production-grade web application. Instead of fragmented servers running on separate ports, all modules share one robust Flask backend running at http://127.0.0.1:5000.

The system demonstrates progressive web development concepts: starting with simple HTTP POST form handling and server-side validation (Practical 1 & 2), moving to full relational database CRUD lifecycles, constraint enforcement, and search queries using SQLite (Practical 3 & 4).
